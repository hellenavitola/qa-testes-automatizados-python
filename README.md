# Projeto de QA — Testes Automatizados com Python e Pytest

## Sobre o projeto

Este projeto tem como objetivo aplicar conceitos de Quality Assurance (QA) por meio da criação e execução de testes automatizados utilizando Python e Pytest.

O desenvolvimento faz parte do meu portfólio acadêmico e profissional na área de Tecnologia da Informação, com foco no aprendizado prático de automação de testes de software.

## Tecnologias utilizadas

- Python
- Pytest
- Visual Studio Code

## Testes implementados

O projeto contempla testes de operações matemáticas e validações de comportamento, incluindo:

- Teste de soma;
- Teste de subtração;
- Teste de multiplicação;
- Teste de divisão;
- Validação de divisão por zero;
- Testes parametrizados com diferentes valores de entrada.

## Execução dos testes

Para executar os testes, utilize o comando:

```bash
python -m pytest -v
```

## Instalação das dependências

Para instalar as dependências do projeto:

```bash
python -m pip install -r requirements.txt
```

## Resultados

Os testes foram executados com sucesso, incluindo cenários positivos, negativos e parametrizados.

## Objetivo de aprendizado

Desenvolver conhecimentos práticos em automação de testes, lógica de programação, identificação de falhas e validação de funcionalidades de software.
